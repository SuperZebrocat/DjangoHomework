# Разработка интернет-магазина

## Описание проекта

Данный проект представляет собой сайт интернет-магазина. 
Он включает в себя Django-проект, функционал которого релизован в приложении catalog. 

Цели проекта:
1) Подготовка шаблонов для отображения страниц интернет-магазина.
2) Стилизация шаблонов с помощью Bootstrap.
3) Реализация котроллеров для отображения страниц.
4) Настройка маршрутизации для этих контроллеров.
5) Реализация формы обратной связи на странице контактов.
6) Настройка обработки данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.

## Установка

1. Клонируйте репозиторий по ссылке https://github.com/SuperZebrocat/DjangoHomework

2. Установите необходимые зависимости: для работы над проектом необходимо установить Django.

4. Точка входа находится в модуле manage.py в корне проекта

## Использование
1. Для запуска сервера разработки выполните команду "python manage.py runserver".
2. Для перехода на домашнюю страницу введите адрес в адресной строке: http://127.0.0.1:8000/home/.
3. Для перехода на страницу контактов введите адрес в адресной строке:http://127.0.0.1:8000/contacts/.
4. При корректном заполнении формы обратной связи пользователь получит сообщение об успешной отправке данных.
